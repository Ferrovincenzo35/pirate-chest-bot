PIRATE CHEST BOT — BETA PRIVATA

COSA CONTIENE
- Interfaccia mobile scura/oro.
- Anteprima fotocamera posteriore.
- Contatore manuale delle casse per sessione.
- Statistiche locali, cronologia, record e media.
- Classifica amici locale (inserimento manuale).
- Esportazione CSV.
- Manifest e service worker per installazione PWA.

IMPORTANTE
Questa beta NON riconosce ancora automaticamente le casse. La fotocamera mostra il video, ma il conteggio avviene con il pulsante +. Non sono implementati sincronizzazione online, account, classifica condivisa, pubblicità o backend.

COME PROVARLA
La fotocamera del browser richiede un contesto sicuro HTTPS (oppure localhost). Per usarla su iPhone:
1. Pubblica questi file su un hosting statico HTTPS (ad esempio un hosting statico a tua scelta).
2. Apri il link con Safari.
3. Premi Condividi > Aggiungi alla schermata Home.
4. Apri l'icona dalla Home e concedi l'accesso alla fotocamera.
5. I dati restano nel browser/dispositivo. Non cancellare i dati del sito se vuoi conservarli.

PER PASSARLA AGLI AMICI
Condividi lo stesso link HTTPS. Ogni amico avrà i propri dati sul proprio dispositivo. Questa versione non condivide automaticamente le statistiche tra telefoni.
